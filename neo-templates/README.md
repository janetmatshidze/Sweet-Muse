# Neo.Templates

The place for code &amp; file templates of all kinds

## Neo react

Notes on how to test the neo-react template on your local machine

```Bash
# In a terminal
# Navigate to the template folder
neo.templates/Client/neo-react
# Symlink the package folder
npm link

# Navigate to the folder where you want to test the yeoman neo-react.
# Example folder
cd ~/Desktop/testTemplate

# Generate the template
yo generator-neo-react
```
